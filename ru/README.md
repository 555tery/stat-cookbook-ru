# Русская версия

Перевод и адаптация: Danil Pokulevskii (@555tery), 2026.

Исходный файл перевода — `stat-cookbook-ru.tex`. Он основан на английской
версии `stat-cookbook.tex` версии 0.2.7; текущая версия перевода — 0.2.9.
Оригинал, общие математические макросы и библиография переиспользуются без
изменений. Графики распределений строятся
из общего R-скрипта с русскими подписями и сохраняются отдельно в `ru/figs/`.

Из корня репозитория соберите PDF командой:

```sh
make ru
```

Для сборки нужны R с пакетами, используемыми `figs/distributions.R`, Tectonic
(движок на основе XeTeX) и шрифты Times New Roman, Arial и Courier New. PDF
появится в `ru/stat-cookbook-ru.pdf`.

Схема связей распределений на последней странице оставлена на английском:
в репозитории оригинала она доступна только как готовый PDF без редактируемого
исходника. Формулы сохранены по оригиналу; перечень замеченных в нём возможных
математических неточностей приведён в `PLAN.md` и требует отдельной сверки.
